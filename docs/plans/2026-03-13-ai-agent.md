# AI Agent Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an AI agent (Anthropic Claude-compatible API) that handles free-text messages with streaming responses, tool use for calendar operations, and persistent chat history.

**Architecture:** The AI agent sits as a fallback message handler: when no scene is active and the message is free text, it delegates to `CalendarBotAgent` which builds a system prompt with context (user info, today/tomorrow events), streams the response via throttled `editMessageText`, and uses tools to call existing `EventService`, `HolidayService`, and `UserRepository`. Chat history is stored in SQLite and loaded as context (last 20 messages). Only final assistant text responses are saved to history.

**Tech Stack:** Bun, GramIO, @anthropic-ai/sdk, bun:sqlite, pino
