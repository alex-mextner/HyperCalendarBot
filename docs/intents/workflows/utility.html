Время и вычисления

Текущее время здесь или в городе

basis.time.now · Back to rule

{
  "version": 2,
  "bindings": {
    "city": {
      "type": "text",
      "from": "{{$1|default(\"\")}}",
      "max": 40,
      "optional": true,
      "default": ""
    }
  },
  "steps": [
    {
      "when": "bind.city == ''",
      "call": "get_timezone_info",
      "input": {
        "timezone": "{{user.timezone}}"
      }
    },
    {
      "when": "bind.city != ''",
      "call": "get_timezone_info",
      "input": {
        "timezone": "{{bind.city}}"
      }
    }
  ],
  "i18n": {
    "ru": {},
    "en": {}
  }
}

Перевести моё время сегодня в другой часовой пояс

basis.time.convert · Back to rule

{
  "version": 2,
  "bindings": {
    "d": {
      "type": "date",
      "from": "today",
      "words": {
        "today": "today"
      }
    },
    "at": {
      "type": "time",
      "from": "{{$1}}"
    },
    "when": {
      "type": "datetime",
      "date": "d",
      "time": "at"
    },
    "tz": {
      "type": "timezone",
      "from": "{{$2}}"
    }
  },
  "steps": [
    {
      "call": "convert_to_timezone",
      "input": {
        "datetime": "{{bind.when}}",
        "timezone": "{{bind.tz}}"
      },
      "as": "c"
    },
    {
      "respond": "{{t.out}}"
    }
  ],
  "i18n": {
    "ru": {
      "out": "{{tool_outputs.c.local_datetime}} ({{tool_outputs.c.timezone}})"
    },
    "en": {
      "out": "{{tool_outputs.c.local_datetime}} ({{tool_outputs.c.timezone}})"
    }
  }
}
